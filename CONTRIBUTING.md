# Contributing

Thanks for helping improve the organization-level GitHub community files. These
files can affect repository defaults across the account, so changes should be
small and easy to audit.

## Local Setup

Clone the repository:

```bash
git clone https://github.com/Scottcjn/.github.git
cd .github
```

No build step is required for the current Markdown files.

## Contribution Guidelines

- Keep organization defaults generic and reusable.
- Avoid project-specific instructions that belong in an individual repository.
- Use clear Markdown headings and concise language.
- Do not include secrets, private contact details, or unstable links.

## Validation

Run:

```bash
git diff --check
```

For Markdown changes, preview the rendered file before opening a pull request.

## Pull Request Checklist

- Explain which default community file changed.
- Note any links you verified.
- Link the related issue or bounty, if applicable.
